================================================================================
                        TASKGUARD EXTENSION - CODE EXPLANATION
================================================================================

TaskGuard is a Chrome extension that helps users stay focused by allowing them
to set a focus timer with a specific intent/task. Below is a detailed
explanation of each file and its components.

================================================================================
1. MANIFEST.JSON - Extension Configuration
================================================================================

This file defines the extension's metadata and permissions for Chrome.

- manifest_version: 3
  Uses Manifest V3 (the latest Chrome extension format).

- name/version/description
  Basic extension info displayed in Chrome's extension manager.

- permissions: ["storage", "alarms"]
  - storage: Allows saving data (timer state, intent) to Chrome's local storage
  - alarms: Enables scheduling (though not actively used in current code)

- background.service_worker: "background.js"
  Defines the background script that runs persistently to manage the timer.

- action.default_popup: "blocked.html"
  Sets the popup that appears when clicking the extension icon.

================================================================================
2. BACKGROUND.JS - Background Service Worker
================================================================================

This script runs in the background and manages the extension badge timer.

VARIABLES:
----------
- badgeInterval (line 3): Stores the interval ID for updating the badge.

CHROME EVENT LISTENERS:
-----------------------
- chrome.runtime.onMessage (lines 6-12)
  Listens for messages from the popup:
  - 'startTimer': Begins the badge countdown
  - 'stopTimer': Stops and clears the badge

- chrome.runtime.onStartup (lines 15-17)
  Checks for existing timer when Chrome starts up.

FUNCTIONS:
----------
- checkExistingTimer() (lines 22-35)
  Purpose: Restores timer state after browser restart
  - Reads timerEndTime from storage
  - If time remains, restarts the badge timer
  - If expired, cleans up storage and clears badge

- startBadgeTimer(endTime) (lines 37-47)
  Purpose: Initializes the badge countdown display
  - Clears any existing interval to prevent duplicates
  - Calls updateBadge immediately, then every 1 second

- stopBadgeTimer() (lines 49-55)
  Purpose: Stops the timer and clears the badge
  - Clears the interval
  - Removes badge text

- updateBadge(endTime) (lines 57-93)
  Purpose: Updates the extension icon badge with remaining time
  - Calculates remaining time in milliseconds
  - If timer finished:
    - Stops the badge timer
    - Clears storage data
    - Shows "Done" badge (green) for 5 seconds
  - Otherwise displays time in appropriate format:
    - Hours (e.g., "2h") if >= 60 minutes
    - Minutes (e.g., "25m") if >= 1 minute
    - Seconds (e.g., "45s") if < 1 minute

- clearBadge() (lines 95-97)
  Purpose: Removes all text from the extension badge

================================================================================
3. BLOCKED.HTML - Main Popup Interface
================================================================================

This is the popup UI shown when clicking the extension icon.

STRUCTURE:
----------
- Header: "TaskGuard" title

- Intent Entry Section (#intent_entry):
  - #intent_input: Text field for user's focus intent
  - #task_description: Text field for detailed task description

- Timer Selection Section (#select_timer):
  - .timer-label: Shows "Focus Duration:" or "Time Remaining:"
  - .timer-buttons: Four preset duration buttons (15m, 25m, 45m, 60m)
  - #timer_display: Shows countdown when timer is active (hidden by default)

- #submit_intent: Button to start/end focus session

STYLING:
--------
- Minimum width: 300px (standard popup size)
- Timer buttons: Blue outline, white background; blue background when selected
- Submit button: Green background (#28a745)
- Timer display: Large 24px bold text, centered

================================================================================
4. BLOCKED.JS - Popup Logic
================================================================================

Handles all user interactions in the popup.

VARIABLES:
----------
- selectedMinutes (line 1): Tracks which timer duration is selected (0 by default)

DOM CONTENT LOADED HANDLER (lines 3-18):
----------------------------------------
- Calls loadTimerState() to check for active session
- Sets up click handlers for timer buttons:
  - Removes 'selected' class from all buttons
  - Adds 'selected' to clicked button
  - Updates selectedMinutes from button's data-minutes attribute
- Attaches startFocusSession to submit button

FUNCTIONS:
----------
- loadTimerState() (lines 20-52)
  Purpose: Restores UI to match active timer (if any)
  - Checks Chrome storage API availability
  - Gets timerEndTime, intent, taskDescription from storage
  - If timer is running:
    - Hides intent entry section
    - Hides timer selection buttons
    - Changes label to "Time Remaining:"
    - Shows timer display with countdown
    - Changes button to "End Session"
    - Starts 1-second update interval

- updateTimerDisplay(ms) (lines 54-60)
  Purpose: Formats and displays remaining time
  - Converts milliseconds to MM:SS format
  - Uses padStart(2, '0') for leading zeros

- startFocusSession() (lines 62-96)
  Purpose: Begins a new focus session
  - Validates Chrome APIs are available
  - Gets intent and task description from inputs
  - Validates intent is entered
  - Validates a duration is selected
  - Calculates end time: current time + (minutes * 60 * 1000)
  - Saves to Chrome storage:
    - intent
    - taskDescription
    - timerEndTime
    - timerMinutes
  - Sends 'startTimer' message to background script
  - Redirects to allowlist.html

- endSession() (lines 98-107)
  Purpose: Manually ends the focus session
  - Removes all timer data from storage
  - Sends 'stopTimer' message to background script
  - Reloads the popup to show initial state

================================================================================
5. ALLOWLIST.HTML - Allowlist Management Page
================================================================================

A page for managing allowed websites during focus sessions.

STRUCTURE:
----------
- Header: "Welcome to the Allowlist Page"
- Description paragraph
- #allowlist_input: Text field to enter website URLs
- #add_allowlist: Button to add website to list
- #allowlist_display: Unordered list showing allowed sites

NOTE: Currently, the allowlist is only stored in the DOM (not persistent).

================================================================================
6. ALLOWLIST.JS - Allowlist Logic
================================================================================

Handles adding websites to the allowlist.

DOM CONTENT LOADED HANDLER (lines 2-17):
----------------------------------------
Purpose: Sets up the add-to-list functionality
- Gets references to button, input, and list elements
- Returns early if button not found (safety check)
- On button click:
  - Validates input and list exist
  - Gets trimmed input value
  - Returns if value is empty
  - Creates new <li> element with the website
  - Appends to the list
  - Clears the input field

================================================================================
DATA FLOW SUMMARY
================================================================================

1. USER STARTS SESSION:
   blocked.html -> blocked.js (startFocusSession)
   -> Chrome storage (save timer data)
   -> background.js (startTimer message)
   -> allowlist.html

2. TIMER RUNNING:
   background.js (updateBadge every 1s)
   -> Extension badge shows countdown

   blocked.js (loadTimerState)
   -> Popup shows remaining time

3. TIMER ENDS:
   background.js (updateBadge detects remaining <= 0)
   -> Shows "Done" badge
   -> Clears storage
   -> Clears badge after 5s

4. USER ENDS EARLY:
   blocked.js (endSession)
   -> Clears storage
   -> Sends stopTimer to background
   -> Reloads popup

================================================================================
CHROME APIS USED
================================================================================

- chrome.storage.local.get()     : Read data from local storage
- chrome.storage.local.set()     : Write data to local storage
- chrome.storage.local.remove()  : Delete data from local storage
- chrome.runtime.onMessage       : Listen for inter-script messages
- chrome.runtime.sendMessage()   : Send messages between scripts
- chrome.runtime.onStartup       : Event fired when Chrome starts
- chrome.action.setBadgeText()   : Set extension icon badge text
- chrome.action.setBadgeBackgroundColor() : Set badge background color
